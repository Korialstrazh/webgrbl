# webgrbl Wiki

Entry point of the LLM-maintained knowledge base (see `docs/rulesets/rules/common/obsidian-rag.rule.md`). Each topic folder has its own `_index.md`.

- [product](product/_index.md) - What webgrbl is for: goals, platform constraints, feature backlog.
- [architecture](architecture/_index.md) - How the source is structured: app shell, state, PWA, localization, tooling.
- [lasergrbl](lasergrbl/_index.md) - Reference catalog of every LaserGRBL feature (behaviour, defaults, GRBL commands, upstream source links) with the webgrbl parity checklist.
