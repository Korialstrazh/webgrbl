# Material library

Presets hold the power, speed and passes that work for a material on one machine. The design is in `docs/superpowers/specs/2026-11-04_(01)_material-library.spec.md`.

- **Where things live:** model and file handling in `src/utils/materials/`, state in `src/utils/states/material.preset.*`, UI in `src/containers/MaterialLibraryDialog/`. The entry point is `MaterialSection` in the Material panel of the Design view (book button and preset summary line, count from `selectActiveMaterialPresetCount`); the layer drawer's `LayerPresetButtons` opens the same dialog with `initialLayerKey`.
- **Dialog state:** `MaterialLibraryEditor` owns the draft the form edits, compares it with the stored preset (`isSameMaterialPreset`) to decide whether Save or Apply is the main action, and shows one confirmation line (`role="status"`) at the bottom of the edit pane. `MaterialPresetTable` renders the rows; with `rowApply` set (opened from a layer) each row of the active machine gets an Apply button. `useApplyPresetToLayer` is the one place that applies a preset to a layer, used by the edit pane and the row buttons.
- **Duplicates from a layer:** `getMatchingMaterialPreset` finds the stored preset of the same material, operation and machine; `LayerPresetButtons` then asks Update existing or Save as new in a Popconfirm. Updating keeps the id and the notes of the stored preset.
- **Storage:** the `materialPresets` Dexie table. Only `MATERIAL_PRESET_REPOSITORY` touches it, and `watchMaterialPresets` keeps it in step with the state.
- **Add a field to a preset:** change `MaterialPreset`, `isMaterialPreset` and the form. Stored rows without the field are left out by the guard, so give old rows a Dexie upgrade. Also update the file format, and raise `MATERIAL_PRESETS_FILE_VERSION` if old files can no longer be read.
- **Power:** always stored in watts. Convert with `getPresetLayerSettingsChange` (to a layer) and `newMaterialPresetFromLayer` (from a layer). `getImportedMaterialPresets` rescales a file for the importing laser.
